Install guide

Quran Reader for Linux

A free Quran app for Linux that works without internet. Read the Madani Mushaf page by page or a whole Surah at once, with recitation, Tafsīr Ibn Kathīr and al-Jalālayn, and daily reading routines. Packaged for Debian, Ubuntu, Fedora, openSUSE and Arch, and as an AppImage for everything else.

.deb .rpm AppImage

Needs a 64-bit (x86_64) system with glibc 2.35 or newer: Ubuntu 22.04, Debian 12, Fedora 36, Linux Mint 21 or anything newer.

Ubuntu, Debian, Linux Mint, Pop!_OS

Download the .deb above, then from the folder you saved it in:

sudo apt install ./Quran.Reader_*_amd64.deb

Fedora, openSUSE

Download the .rpm above, then:

sudo dnf install ./Quran.Reader-*.x86_64.rpm      # Fedora
sudo zypper install ./Quran.Reader-*.x86_64.rpm   # openSUSE

Arch, Manjaro, EndeavourOS, CachyOS

Install quran-reader-bin from the AUR with your helper of choice: 

yay -S quran-reader-bin

It updates with the rest of your system.

Any other distribution: AppImage

Download the AppImage above, make it executable and run it:

chmod +x Quran.Reader_*_amd64.AppImage
./Quran.Reader_*_amd64.AppImage

If it won't start on Ubuntu 22.04 or newer, install FUSE 2 first: sudo apt install libfuse2 (on 24.04, libfuse2t64).

Update

On Arch, updates come through the AUR. Otherwise, install the newest .deb, .rpm or AppImage the same way. Your reading position, history, bookmarks and routines are kept.

What you get

The full Quran text and all 604 Mushaf pages built in, so it reads with no connection. Focus mode and full screen (F11) for reading without distraction, auto-scroll at your own pace, your reading history, recitation from five reciters, Tafsīr Ibn Kathīr and al-Jalālayn in Arabic and English, and daily routines. See all features.
